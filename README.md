# 📄 Currículo Web Interativo

Um currículo digital dinâmico e responsivo desenvolvido com as tecnologias fundamentais da web (HTML, CSS e JavaScript puro). Este projeto não apenas apresenta minha trajetória profissional e acadêmica, mas também serve como um portfólio prático das minhas habilidades de desenvolvimento e estruturação de interfaces.

## ✨ Funcionalidades

- **Alternância Dinâmica de Perfis (Toggle):** Através de JavaScript, o currículo permite alternar instantaneamente entre duas versões do meu perfil ("Versão TI" e "Versão Administrativa"). Os dados são carregados dinamicamente sem necessidade de recarregar a página.
- **Exportação Otimizada para PDF:** Um botão de "Exportar PDF" que aciona a impressão nativa do navegador (`window.print()`), aliado a estilos CSS específicos (`@media print`) que removem elementos visuais de navegação e garantem uma formatação limpa e profissional para salvamento em PDF.
- **Design Moderno:** Interface estruturada utilizando CSS Grid para o layout principal (dividindo a barra lateral e o conteúdo), variáveis CSS para controle de paleta de cores e chips arredondados para listagem de habilidades.
- **Arquitetura de Dados:** Separação entre a estrutura (HTML) e os dados do currículo, utilizando objetos JavaScript estruturados para armazenar as experiências, projetos e habilidades.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Marcação semântica da página.
- **CSS3:** Flexbox, Grid Layout, Media Queries (Print) e CSS Custom Properties (Variáveis).
- **JavaScript (Vanilla):** Manipulação do DOM e injeção dinâmica de conteúdo.
