# 📄 Currículo Web Interativo

Tinha dificuldade com o Microsoft Word e precisava atualizar meu curriculo regularmente e ele sempre ficava com algum problema de rodapé ou cabeçalho. Então decidi Desenvolver um protótipo em Html5, que seria necessário apenas modificar as <divs> e atualizar as minhas informações. Ao decorrer do tempo precisei ter dois perfis de curriculos, pois aplicava para área administrativa e de Tecnologia, daí eu refinei o projeto adcionando os estilos em CSS e um Javascript e o projeto tinha se tornado algo funcional e com utilidade pública. Hoje em dia não tenho mais dificuldades com o word lol, então faço a caridade de distribuir meu projeto no[GitHub](https://github.com/dev-renanvt/web-Curriculum) para que pessoas como eu com dificuldades em Word possam utilizar livremente.

## ✨ Funcionalidades

- **Alternância Dinâmica de Perfis (Toggle):** Através de JavaScript, o currículo permite alternar instantaneamente entre duas versões do meu perfil ("Versão TI" e "Versão Administrativa"). Os dados são carregados dinamicamente sem necessidade de recarregar a página.

- **Exportação Otimizada para PDF:** Um botão de "Exportar PDF" que aciona a impressão nativa do navegador (`window.print()`), aliado a estilos CSS específicos (`@media print`) que removem elementos visuais de navegação e garantem uma formatação limpa e profissional para salvamento em PDF.

- **Arquitetura de Dados:** Separação entre a estrutura (HTML) e os dados do currículo, utilizando objetos e Manipulação de DOm em JavaScript estruturados para armazenar as experiências, projetos e habilidades.
